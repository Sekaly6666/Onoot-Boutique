1 Architecture Technique du Projet

Le projet Onoot Boutique est composé de 3 modules distincts nécessitant chacun un type d'infrastructure adapté :

1. Boutique Client
Frontend Vite React
Catalogue, panier, commandes WhatsApp, paiements, authentification client.
Dossier : onoot-boutique/onoot-boutique
2. Espace Administrateur
Frontend Vite React
Tableau de bord, gestion des stocks, livreurs, commandes, reporting Excel.
Dossier : onoot-boutique/admin
3. Serveur API & Base
Node Express + MongoDB
API REST, sessions JWT, emails SMTP Brevo, téléversement de fichiers et photos.
Dossier : Onoot-Boutique/api-server

3 Guide Pratique : Déployer Gratuitement en 4 Étapes

  • Créer la base de données gratuite sur MongoDB Atlas

    Créez un compte gratuit sur mongodb.com/atlas, déployez un cluster gratuit M0 (512MB) en région Europe (Frankfurt) ou Irlande, créez un utilisateur et autorisez l'IP 0.0.0.0/0 (accès cloud). Récupérez votre chaîne de connexion mongodb+srv://....

  • Déployer le Backend `api-server` sur Render.com

    1. Connectez-vous sur render.com avec votre compte GitHub.
    2. Cliquez sur New Web Service et sélectionnez votre dépôt Sekaly6666/Onoot-Boutique.
    3. Renseignez les paramètres suivants :
    • Root Directory : Onoot-Boutique/api-server
    • Build Command : npm install && npm run build
    • Start Command : node dist/index.mjs
    • Variables d'environnement : Ajoutez MONGODB_URI, JWT_SECRET, PORT=5005, SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS, SMTP_FROM, SHOP_EMAIL.
    4. Une fois déployé, Render vous fournit l'URL de votre API : https://onoot-api.onrender.com.

  • Déployer la Boutique (`onoot-boutique`) sur Vercel

    1. Rendez-vous sur vercel.com et importez votre dépôt GitHub.
    2. Définissez Root Directory sur : onoot-boutique/onoot-boutique.
    3. Framework Preset : Vite.
    4. Dans Environment Variables, ajoutez :
    • VITE_API_URL = https://onoot-api.onrender.com
    5. Cliquez sur Deploy. Vous obtenez : https://onoot-boutique.vercel.app.

  • Déployer le Panel Admin (`admin`) sur Vercel

    1. Sur Vercel, ajoutez un nouveau projet avec le même dépôt.
    2. Définissez Root Directory sur : onoot-boutique/admin.
    3. Dans Environment Variables, ajoutez :
    • VITE_API_URL = https://onoot-api.onrender.com
    4. Déployez. Vous obtenez : https://onoot-admin.vercel.app.

💡 Synchronisation automatique : Chaque fois que vous ferez un git push sur votre GitHub, Vercel et Render mettront automatiquement à jour vos sites en moins de 2 minutes !

5 Recommandation Finale d'Expert pour Onoot Boutique

🎯 Notre Stratégie Recommandée en 2 Temps :

1. Immédiatement (Tests & Validation) :
Utiliser Vercel (gratuit) pour la Boutique et l'Admin + Render (gratuit) pour l'API Node.js + MongoDB Atlas (gratuit) pour la base de données. Coût total : 0 FCFA. Cela vous permet de valider toutes les fonctionnalités (commandes, livreurs, emails) sur smartphone et PC en situation réelle.

2. Pour le Lancement Officiel (Production) :
Garder les deux frontends sur Vercel (qui reste gratuit même en production avec une vitesse CDN mondiale imbattable) et basculer l'API et les fichiers sur un VPS Hetzner ou Hostinger (~3 500 FCFA/mois) avec un nom de domaine officiel (ex: onoot.ci ou onootboutique.com, coût : ~6 000 FCFA/an). C'est la configuration la plus robuste, rapide et économique du marché.
